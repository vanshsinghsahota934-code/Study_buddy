# Study Buddy PWA

A starter installable web app for Class 9 CBSE + RIMC study support.

## Included
- Home dashboard and daily checklist
- Subject launcher for Mathematics, Science, English and Social Science
- ChatGPT lesson prompt launcher (requires internet and ChatGPT access)
- Local MCQ sample
- Notes saved in the browser on this device
- Study planner saved in the browser on this device
- Web app manifest and service worker for installability/offline app shell

## Install on Android
1. Upload the contents of this folder to an HTTPS static host (for example, GitHub Pages or another static hosting provider).
2. Open the HTTPS website in Chrome on Android.
3. Open Chrome's menu and choose **Install app** or **Add to Home screen**.
4. Tap the new Study Buddy icon on your home screen.

The app cannot be installed directly from this ZIP. It must first be hosted over HTTPS. AI lesson prompts open ChatGPT and need internet. Notes and planner data stay in this browser on this device; they are not synced or backed up. This starter does not yet provide automatic notifications, accounts, cloud sync, or a private AI backend.
